# Planet texture credits

- `earth.jpg`: Earth Day Map, Solar System Scope / INOVE, 8192×4096.
- `moon.jpg`: Moon, Solar System Scope / INOVE, 4096×2048.
- `mars.jpg`, `jupiter.jpg`, `saturn.jpg`: Solar System Scope / INOVE planetary maps, 4096×2048 each.
- `mercury.jpg`, `uranus.jpg`, `neptune.jpg`: Solar System Scope / INOVE planetary maps, 2048×1024 each.
- `venus.jpg`: Solar System Scope / INOVE Venus Atmosphere, 4096×2048.
- `stars.jpg`: Solar System Scope / INOVE Stars + Milky Way, downsampled from 8192×4096 to 4096×2048 and re-encoded as JPEG.
- `saturn-ring.png`: Solar System Scope / INOVE Saturn Ring, 2048×125 with alpha.
- Source: https://www.solarsystemscope.com/textures/
- License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/
- Changes: the Moon and Mars maps were downsampled for the offline viewer. The globe maps were re-encoded as JPEGs. The ring image was re-encoded as an RGBA PNG.
- `earth_lights.png`: Three.js example texture, https://threejs.org/examples/textures/planets/earth_lights_2048.png

Local lunar and Martian terrain is procedurally generated artwork.
