# JUGRE SPACE PROJECT — трейлер

`JUGRE_Space_Project_Trailer_1080p.mp4` — трейлер игры: 1920×1080, 30 к/с, 101 с, H.264 + AAC, громкость −14 LUFS.
`poster.jpg`, `still_liftoff.jpg` и `still_tech.jpg` — кадры из трейлера для превью.

Все игровые кадры записаны из текущей сборки `assembly_hangar/index.html` в движке игры
(Chromium + WebGL/SwiftShader), без отрисовки «поверх» и без подмены моделей.
Поверх видео наложены только титры, плашки, субтитры радиосвязи и цветокоррекция.

## Как сделано

* **Покадровая съёмка с виртуальным временем.** `requestAnimationFrame` и `performance.now()`
  подменяются, и симуляция продвигается ровно на 1/30 с на кадр. Поэтому видео плавное,
  хотя программный рендер выдаёт меньше 1 кадра в секунду.
* **Кинокамера.** Через `?vabDebug` скрипт ставит камеру по заданным траекториям прямо перед отрисовкой
  (`flight.render`), а интерфейс игры скрывается CSS-«кинорежимом».
* **Мультикамерный старт.** Saturn V стартует один раз, а каждый кадр отрисовывается с нескольких ракурсов.
* **Переходы к фазам миссий** — через чекпоинты `FlightState` из исходников игры (как в её Playwright-тестах)
  и загрузку сохранения через «Continue».
* **Монтаж** — HTML-компоузер (`source/comp/comp.html`): переходы, Ken Burns, грейдинг, зерно,
  плашки шрифтами Inter / JetBrains Mono в стиле интерфейса игры.
* **Звук** — оригинальный саундтрек, синтезированный в `source/audio/score.py` (numpy/scipy):
  пэды, арпеджио, ударные, брэмы, рёв двигателей, удары. Реплики ЦУПа — собственные записи игры
  (`assets/audio/radio`), с радиообработкой и квиндар-тонами.
* **SI-эпизод** использует ту же заглушку ответа сервиса, что и тест игры `si-mission.spec.mjs`.
  Реальный сервис SI при съёмке не вызывался.

## Пересборка

Нужен собранный `assembly_hangar/index.html` (LFS), Node 22, Playwright с Chromium, Python 3 с numpy/scipy и ffmpeg.

```bash
cd assembly_hangar/source && node tests/serve.mjs &          # игра на :4179
cd trailer/source && python3 -m http.server 4190 &           # компоузер на :4190
./make_ckpt.sh                                               # чекпоинты фаз миссий
node shot_launch.cjs && node shot_hangar.cjs && node shot_ui.cjs
node shot_flight.cjs ascent,moon,moonship,lm,eva,lmascent,cabin,orion,edl,marslow,rover,draco,dart,iss,reentry,splash,splash8
./final.sh                                                   # монтаж + звук + кодирование
```
