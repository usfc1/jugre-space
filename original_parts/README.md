# JUGRE · Оригинальные детали

Модульный набор для свободного конструктора. Каждая деталь лежит в отдельном GLB в `models/`. В наборе 25 типов деталей и 26 GLB. Две створки обтекателя имеют свои модели, крепления и события сброса.

- `specs.ru.md` и `specs.en.md` — характеристики для русских и английских карточек.
- `manifest.json` — идентификаторы, пути, локализованные названия, игровые числа, размеры, точки крепления и шарниры.
- `preview.png` — общий вид моделей.

## Сборка и анимация

Единицы — метры. Нос ракеты направлен вдоль `+Y`. Узлы `mount_*` содержат профиль и роль крепления. Локальная `+Z` направлена наружу, а `+Y` задаёт ориентацию вокруг оси крепления. При соединении точек совместите их координаты и направьте оси `+Z` навстречу друг другу, сохраняя сонаправленность `+Y`. В Three.js исходный идентификатор узла доступен как `object.userData.partId`.

`jugre_stack_125` и `jugre_stack_250` обозначают номинальные осевые размеры. `jugre_radial` используется на боковых направляющих. У рамы «Триада» три гнезда с `acceptsParts` для К-125. У основания «Пояс» разные профили замка для левой и правой створок. Для подключения исторической детали конструктору нужно сопоставить её точку с профилем JUGRE или поставить переходник. Топливо, питание и ограничения по массе проверяются по характеристикам деталей.

В GLB солнечного крыла и решётчатого руля есть клип `deployment`. Первый кадр — сложенное положение, последний — раскрытое. Рули имеют собственные оси отклонения. Для отделителей и створок манифест задаёт тип события ступени, которым управляет игра.

## Повторный экспорт

В каталоге `source` выполните `npm ci`, затем `npm run build`. Генератор пересобирает модели, манифест и обе языковые версии спецификаций из одного набора данных. Геометрические примитивы взяты из исходников предыдущего набора JUGRE.
